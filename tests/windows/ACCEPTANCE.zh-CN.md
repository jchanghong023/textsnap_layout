# Windows 11 x64 实机验收

本清单只能在目标 Windows 11 x64 实机上签署。ARM64 Linux 上的单元测试、
真实 OCR 冒烟测试和 PE 静态检查不能替代这里的结果。

## 前置条件

- 使用发布门禁通过后生成的 `TextSnapLayout-0.1.0-win-x64.zip`，先核对同名
  `.sha256`。
- 测试机为 Intel i7-13700，未安装供本应用使用的系统 Python；断开网络。
- 分别解压到普通路径、含空格路径和含中文字符路径。不要在 ZIP 内直接运行。
- 打开任务管理器、资源监视器和注册表编辑器，准备记录时间与内存数据。
- 保存发布门禁产生的 `TEXTSNAP_REAL_OCR_RECORD`。该门禁必须使用清单锁定版本的
  Pillow、NumPy、OpenCV、PaddlePaddle、PaddleOCR、PaddleX 和锁定字体，在进程
  内从受控语料生成 1920×1080 与 3840×2160 像素图；任何 `skipped` 结果都不算
  通过。
- 在浏览器中打开 `tests/fixtures/html/controlled-corpus.html`，按清单要求设置
  视口和缩放。同时打开 `corpus-manifest.json` 和
  `controlled-corpus.expected.txt` 作为锚点、版本和 ground truth 依据。浏览器只
  用于人工显示检查；自动真实 OCR 门禁不得启动浏览器或访问网络。

## 必测行为

1. 双击根目录 `TextSnapLayout.exe`，确认没有控制台窗口，托盘出现且首次提示
   默认快捷键；以 `--autostart` 启动时不显示该提示。
2. 再次双击，确认没有第二个常驻进程，已有实例打开设置窗口。
3. 验证 `Ctrl+Alt+O`，录制并保存新快捷键；用已被其他程序占用的组合验证冲突
   提示及旧快捷键保留。
4. 启用和关闭开机启动，核对
   `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中只修改
   `TextSnapLayout` 值。移动程序前先关闭开机启动；若保持启用后移动，运行新位置
   应更新该值。
5. 在 100%、125%、150% 和 200% DPI 下分别测试正向拖动、反向拖动、`Esc`、
   右键、7×8、8×7 和 8×8 像素边界。选区与冻结画面的物理像素必须一致，
   不得跨屏选取或包含鼠标指针。
6. 模型加载期间立即截图，确认窗口显示“等待模型就绪…”，就绪后只提交一次。
   识别期间重复按热键只提示忙碌，不排队。
7. 对网页、文档、代码、长行、双栏、反色和 4K 小字样本执行识别，并逐项对照
   `controlled-corpus.expected.txt`：每个 `line_anchors` 锚点必须恰好出现一次，
   不得丢失、合并或新增非空文字行；忽略布局空白后的正文字符错误率必须不高于
   2%；每个 `geometry_anchors` 的输出行号和半角网格列号与 ground truth 的偏差
   均不得超过一行或一个半角单元。4K 输出中的 `LONG-LINE`/`END-LONG-LINE` 和
   `4K-SMALL-TEXT`/`END-4K` 必须分别位于同一行且只出现一次，以确认分块接缝没有
   重复或截断。另核对内部空格、代码缩进、栏距、空行、无多余尾随空格和无额外
   结尾换行。
8. 测试局部复制、`Ctrl+C`、`Ctrl+A` 和“复制全部”；缩放结果窗口不得产生
   真实换行，复制后窗口不得自动关闭。
9. 已有结果存在时，分别触发截图取消、空结果、OCR 失败和识别中取消；旧结果
   必须恢复。只有成功结果可以替换旧结果。
10. 识别中退出，确认先请求取消；10 秒内不得提供强制退出，超过 10 秒后才允许
    用户明确选择。正常退出不得强制终止 OCR 线程。
11. 使用资源监视器确认无外连。运行前后使用 `snapshot_bundle.ps1` 核对程序目录：
    除用户明确保存的 `data/settings.json` 外，不得新增或改变截图、文本、日志、
    字节码、缓存或其他文件。
12. 记录后台预加载时间、常驻内存、OCR 峰值内存、普通选区耗时和 4K 全屏耗时；
    界面必须保持可重绘并允许取消。
13. 记录 SmartScreen“未知发布者”行为，以及普通桌面之外的 UAC 安全桌面、
    DRM/受保护视频和系统返回全黑表面不受支持的提示。

## 结果记录

每个 DPI 和解压路径都记录 Windows 版本、显示器布局、缩放、通过/失败、复现步骤
和不含真实用户截图或识别内容的去敏诊断。另附
`TEXTSNAP_REAL_OCR_RECORD` 中的 Python/平台、依赖精确版本、字体 SHA-256、两张
渲染图像 SHA-256、CER 和行数；记录不包含 OCR 输出正文。自动门禁被跳过、任何
量化指标未记录，或任何 Win32 热键、DPI/GDI、托盘、单实例、开机启动、DLL 加载
或 SmartScreen 项未执行时，对应结论必须保持“待 Windows 11 x64 实机验证”。

仓库外的自动包验收可由解压包自己的 `runtime/pythonw.exe` 执行
`-I -B tests/windows/verify_extracted_bundle.py --bundle <解压根目录>
--result <包外结果.json>`。除最终 JSON 外，脚本会实时追加
`<包外结果.json>.progress.jsonl`，记录运行时、清单快照、依赖、Qt、命名管道、
模型加载、真实 OCR、线程清理和运行后快照各阶段的累计耗时与状态。若无界面进程
停滞，可直接查看最后一行确定卡住阶段；日志不含截图或 OCR 正文。
